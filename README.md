# Learn JavaScript, TypeScript, and Playwright

A collection of learning materials and examples for JavaScript, TypeScript, and Playwright. The repository is organized into numbered chapters; JavaScript examples can be run individually with Node.js.

## Repository contents

- `00_chapter_Prompt_Eng/` — prompt-engineering references and test-plan examples, including the RICE-POT framework.
- `01_chapter_JS_Basics/` — JavaScript fundamentals, including a Hello World example and basic math.
- `02_chapter_JS_keywords_Identifiers/` — JavaScript engine, keywords, comments, and identifier examples.

## Running a JavaScript example

Install [Node.js](https://nodejs.org/) and run an example from the repository root:

```powershell
node .\01_chapter_JS_Basics\01_HelloWorld.js
```

Examples are standalone files. Some files are notes or demonstrations of invalid syntax, so review a file before executing it.
