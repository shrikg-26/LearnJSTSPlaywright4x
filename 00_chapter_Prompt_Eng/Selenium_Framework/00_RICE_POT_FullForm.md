
# RICE-POT Prompt Framework

| Letter | Component | Description | Example for Software Testing |
|---|---|---|---|
| **R** | **Role** | Defines the persona or expertise the AI should adopt. | Act as an Expert QA Automation Engineer. |
| **I** | **Instructions** | Provides specific, step-by-step commands and constraints. | Create Selenium test scripts and identify positive and negative test scenarios. |
| **C** | **Context** | Provides background information about the application or task. | The application has a Salesforce login page with username, password, and login button fields. |
| **E** | **Example** | Supplies a sample or reference to guide the expected result or format. | Follow a PageFactory-based Page Object Model (POM) example. |
| **P** | **Parameters** | Defines quality standards, technical constraints, and rules to follow. | Use Java, Selenium 4, explicit waits, reusable methods, and clean coding practices. |
| **O** | **Output** | Specifies exactly what deliverables the AI must produce. | Provide test cases, page classes, test scripts, Maven dependencies, and execution steps. |
| **T** | **Tone** | Specifies the communication style and level of detail. | Use a technical, precise, professional, and beginner-friendly tone. |
